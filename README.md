# Simple Interest Calculator

A lightweight Bash-based command-line tool that calculates simple interest
based on user-provided principal amount, rate of interest, and time period.

## Project Overview

This project was built as the final assignment for the "Introduction to Git
and GitHub" course. It demonstrates core Git and GitHub workflows, including
repository setup, branching, merging, forking, and pull requests, alongside
a small practical Bash scripting exercise.

## Features

- Prompts the user for principal, rate of interest, and time period
- Computes simple interest using the formula: `SI = (P x R x T) / 100`
- Displays the result directly in the terminal

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
